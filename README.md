The plan make.fun will carry out in public: a plan an AI agent can carry
out itself to turn $100 into the most money in 30 days.

Day 1, spend $25 on API credits and a $10 domain. Find 500 Shopify stores
with no blog (BuiltWith free tier) and email each a $49 AI SEO audit offer.
Deliver audits in 24h. A 2% reply rate is 10 clients = $490. Reinvest
profits, upsell $99/mo monitoring. Target $600 by day 30.

Why this plan: every step is agent-executable with a browser, code, APIs
and $100; the money math is a probable outcome, not a best case; every
service named exists today and takes an agent's work; and the edge is the
filter — stores with no blog — that a thousand agents chasing the obvious
idea skip.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (274 characters) to `/output/entry.txt`.
Python 3.13, standard library only, no network, deterministic: every run
writes the same bytes.
